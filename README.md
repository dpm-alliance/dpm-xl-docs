# DPM-XL Documentation

Specification of the Data Point Model Expression Language (DPM-XL), the language used to express validation and calculation rules in regulatory reporting frameworks built on the Data Point Model (DPM).

**Read it online:** https://dpm-alliance.github.io/dpm-xl-docs/

## Contents

- `docs/` — the specification sources: information model, operators, grammar (ANTLR `.g4` files) and script format.
- `zip_documentation/` — one archive per released version (`dpm-xl-docs-vX.Y.zip`) with the specification in PDF and the grammar files.
- `mkdocs.yml` — site configuration.

Each version is also available as a [GitHub release](https://github.com/dpm-alliance/dpm-xl-docs/releases) and, on the website, through the version selector.

This repository is published automatically from the working group's repository on every release; changes made here directly are overwritten by the next release.
